TALOFA GITHUB PAGES UPLOAD

1. Open the talofa repository on GitHub.
2. Upload every file and the assets folder from this package into the repository root.
3. Replace existing files when prompted.
4. Commit the upload to the main branch.
5. In Settings > Pages, use main / (root).

Important before launch:
- Replace [PHONE], [EMAIL], [SERVICE_AREA], [OPERATING_HOURS],
  [REGISTRATION_LINE], and [FOUNDER_STORY].
- The contact form opens the visitor's email application and sends to [EMAIL].
- CNAME connects the repository to talofasupportservices.com.au.
